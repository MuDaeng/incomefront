# incomefront

income 배당 포트폴리오 API의 프론트엔드 (React + MUI, Vite)

## Scripts

- `npm start` — 개발 서버 (http://localhost:3000, 백엔드는 `.env.local`의 `REACT_APP_API_URL`)
- `npm run build` — 타입 체크 후 `build/`에 프로덕션 빌드 (`.env.production`)
- `npm run preview` — 빌드 결과를 로컬에서 띄우기
- `npm run lint` — ESLint (경고도 실패)
- `npm test` — Vitest watch 모드, `npx vitest run`은 한 번만 실행
